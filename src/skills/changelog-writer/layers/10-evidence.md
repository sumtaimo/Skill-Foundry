# Layer 10: Evidence

Keep the proof behind the answer clear.

1. Record the inputs used: skill name, current version, date and the changes, each marked "from user" or "from file:line".
2. Record the files read and the files not found.
3. Record each check from layer 07 that was run, and its result.
4. Separate confirmed facts from assumptions; an assumption is never written into the entry.
5. Put this record in the reply only when the user asks for it; the bump and mismatch lines already carry the key proof.
