# Layer 09: Handoff

Say what the maintainer does next.

1. Tell them where to paste the entry: at the top of the skill's `CHANGELOG.md`, above the newest entry.
2. List each file that must be set to the new version (from the mismatch list).
3. List the open questions from layer 08, if any.
4. When the change is breaking, remind them that users of the old behaviour must update.
