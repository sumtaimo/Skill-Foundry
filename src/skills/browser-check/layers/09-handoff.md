# Layer 09: Handoff

1. The user receives the reply and the files in `browser-check-out/` (screenshots, `steps.json`, `report.json` when the script ran).
2. A developer who fixes a FAIL can run the same command again to confirm it passes.
3. A QA agent can turn each FAIL into a bug with its steps, expected and seen result, and screenshot.
4. A test-planner checklist can be the source of the flow; browser-check runs it, it does not write it.

Hands to layer 10: the list of files and the result.
