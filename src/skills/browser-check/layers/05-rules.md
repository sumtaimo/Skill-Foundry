# Layer 05: Rules

1. Apply every rule in `RULES.json` (R-browser-check-1 to R-browser-check-13).
2. A PASS needs a browser result (R-browser-check-1). Reading the HTML or the code is never a PASS.
3. Local addresses only, unless the user typed the address (R-browser-check-3).
4. One plain command per script run (R-browser-check-4); nothing installed, started or run without a yes (R-browser-check-5).
5. Test values only (R-browser-check-6). Report, never fix the app (R-browser-check-9).

Hands to layer 06: any request or situation the rules do not cover.
