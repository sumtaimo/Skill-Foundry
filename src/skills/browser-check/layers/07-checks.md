# Layer 07: Checks

1. Every step in the reply appears in the browser-tool results or the script output, with the same status (PASS, FAIL, NOT RUN).
2. When the first line is the could-not-run sentence, the word PASS appears nowhere in the reply.
3. Every FAIL has what the browser saw and a screenshot path, or says that no screenshot could be taken.
4. Every error and request line is copied as reported; none is added or explained as a code cause.
5. Every screenshot path in the reply is one the tools or the script printed.
6. The address in the header is local, a local file, or typed by the user.
7. Every typed value is a test value or a value the user gave, and the reply names them.

Any "no" goes back to layer 04 or layer 08. Hands to layer 08: the checked reply.
