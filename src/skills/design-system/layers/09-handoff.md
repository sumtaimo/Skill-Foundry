# Layer 09: Handoff

1. Give the report of layer 08 as the whole answer: no text before its heading and none after its Open questions.
2. Keep open questions in their own section, so they are not read as decisions.
3. Tell the user, through the report's "How to use", to load tokens.css (or tokens.gaps.css after their own files) before their own styles, and to set data-theme on the html element to force a mode.
4. For a finished screen built with these tokens, the next step is a polish pass with a UI-polish skill; this skill does not write screens.
5. Hand the list of files, the archetype and the count of text pairs to layer 10.
