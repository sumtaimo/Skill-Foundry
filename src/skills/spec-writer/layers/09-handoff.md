# Layer 09: Handoff

1. Give the document as the whole reply. Write no file.
2. The open questions go to the Product Owner. Each answered question becomes a new statement, and the skill is run again on the completed requirement text to turn it into clauses.
3. The clause ids are stable names: the team cites "AC-3" in tickets, tests and reviews. When the requirement text changes, run the skill again; never renumber by hand.
4. After the feature is built and changed later, a regression checklist for that change is the work of the test-planner skill, when the project has it. This skill never writes it.
5. Hand the document and the counts of clauses, open questions and out-of-scope lines to layer 10.
