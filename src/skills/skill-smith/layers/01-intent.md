# Layer 01: Intent

1. Ask who will use the new skill and in which kind of project. Other people must be able to use it, so do not assume this repository.
2. Ask what a user will say to start it: the goal they state, in their words.
3. Ask what the skill must produce: the real files or text, and how good they must be.
4. Ask what the skill must never do.
5. Write the intent in one sentence. Do not invent answers; ask.
