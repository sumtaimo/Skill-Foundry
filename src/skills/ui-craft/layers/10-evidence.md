# Layer 10: Evidence

1. Record the detected **Stack mode**, **Role mode**, and **Token source** used to build the interface.
2. Record the verified light and dark contrast pairs (text >= `4.5:1`, large headings & borders/focus >= `3:1`).
3. Record visual/responsive check evidence (widths `1440px` and `390px`, light & dark, `prefers-reduced-motion: reduce`, zero horizontal overflow, zero console errors) or state honestly if browser execution was unavailable.
4. Record every lifecycle state verified in the output (default, hover, `:focus-visible`, active/selected, disabled, loading skeleton, empty filter/search, inline error retry).
5. Separate observed verification facts from assumptions (for example default neutral palette chosen because no brand hex was supplied).
