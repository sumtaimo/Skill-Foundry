# Layer 10: Evidence

Keep, for each request, enough to show the rewrite is safe:

1. The input copy, word for word.
2. The numbers, names and legal phrases listed in layer 02.
3. The rewritten copy and the change list as returned.
4. The result of each check in layer 07, and the checklist items answered "no" (or "all yes").
5. The assumptions made (guessed UI jobs, guessed names), marked as assumptions.
6. Never write that a check passed when it was not run.
