# Layer 02: Context

1. List every number in the copy (amounts, counts, dates, percentages), written exactly as given, including currency signs and decimals ("$49.00").
2. List every name and product term (screens, features, plans, brands) with its exact capital letters ("Checkout" stays "Checkout").
3. List every legal phrase: terms, consent, privacy, disclaimers, warranty or liability wording.
4. Note every string the user marked to keep as is (words such as "keep as is", "do not change", "[keep]", "(keep)", or a rule like "leave the quoted labels"). Marked strings are never rewritten (R-copy-tight-12).
5. Note every claim label: a short phrase that says where something comes from or what it proves (for example a label about real output, proof or a source). Its claim wording is kept (layer 04 step 4).
6. Count the words of each string; a string over about 25 words is a long string (layer 04 step 6).
7. Note any tone or length limit the user states (for example "max 20 characters"); it applies to every string.
8. Hand these lists to layer 03; they are the parts that must survive unchanged.
