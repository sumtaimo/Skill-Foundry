# Layer 02: Context

1. List every number in the copy (amounts, counts, dates, percentages), written exactly as given, including currency signs and decimals ("$49.00").
2. List every name and product term (screens, features, plans, brands) with its exact capital letters ("Checkout" stays "Checkout").
3. List every legal phrase: terms, consent, privacy, disclaimers, warranty or liability wording.
4. Note any tone or length limit the user states (for example "max 20 characters"); it applies to every string.
5. Hand these lists to layer 03; they are the parts that must survive unchanged.
