# Layer 01: Intent

1. Read the user's request and find the goal they state: shorten, simplify, tighten or make plain a piece of UI copy.
2. Find the copy itself: the quoted or pasted strings in the request. The request is the only source of copy: never search or edit project files for it, and never offer to (R-copy-tight-9). If there is no copy, ask the user to paste the strings and stop.
3. Name the reader of the copy (the person using the screen) and the UI job of each string: button, label, error, empty state, tooltip.
4. If the request is for long-form docs, a blog post, a translation or a changelog entry, say this skill does not cover it and stop (changelog entries belong to changelog-writer).
5. Write the outcome in one sentence: the same meaning in fewer, plainer words, with every number, name and legal phrase kept exactly.
