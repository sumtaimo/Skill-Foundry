# copy-tight checklist

Answer each item yes or no for every answer. Any no blocks the answer.

1. Every number in the input appears in the output unchanged (R-copy-tight-4).
2. Every name and product term keeps its exact capital letters (R-copy-tight-4).
3. The rewrite means the same thing as the original; a user would act the same way (R-copy-tight-3).
4. Legal text is returned unchanged with `Legal text is returned unchanged.` (R-copy-tight-5).
5. The answer has both `Rewritten copy:` and `What changed:` (R-copy-tight-6).
6. No change bullet contains a removed word or phrase, quoted or not (R-copy-tight-7).
7. Buttons start with a verb; errors say what happened.
8. The change list has at most 5 bullets.
9. The rewrite adds no new action, promise or fact; every next step in it was in the original (R-copy-tight-8).
10. The answer starts with Rewritten copy: and ends with the last change bullet; nothing comes before or after (R-copy-tight-9).
