# Layer 05 — Rules

Apply every visual, token, motion, and accessibility contract without shortcuts.

1. **Zero raw hex colors in SVG:** Every `fill`, `stroke`, and `stop-color` inside `<svg>` MUST reference `var(--...)`, `url(#...)`, `currentColor`, or `none`. Define semantic color values only inside `<style>` `:root` / `[data-theme="dark"]` / `@media (prefers-color-scheme: dark)` blocks (or inherit from the project's `design/tokens.css`).
2. **Design-system token mapping:** Prefer the project's existing tokens (`--color-surface-default`, `--color-surface-raised`, `--color-surface-subtle`, `--color-text-default`, `--color-text-muted`, `--color-border-default`, `--color-border-strong`, `--color-action-primary-bg`, `--color-border-focus`, `--color-success-text`, `--color-warning-text`, `--color-danger-text`) and derive internal mechanism aliases (`--mech-bg`, `--mech-node-bg`, `--mech-track`, `--mech-accent`, `--mech-warn`) from them via `var(--..., fallback)`.
3. **Contrast parity:** Guarantee >= `4.5:1` contrast for all node titles and sublabels and >= `3:1` for node borders, tracks, arrows, and focus rings in both light and dark modes.
4. **GPU-friendly animation:** Animate signals with `stroke-dashoffset`, `transform`, and `opacity` only. Never animate `width`, `height`, `x`, `y`, or layout-triggering CSS properties.
5. **Play/Pause contract:** Clicking the Play/Pause button toggles `data-paused="true"` on the mechanism container, updates `aria-pressed` and button label (`Pause animation` / `Play animation`), sets `animation-play-state: paused` on all animated descendants, and calls `svg.pauseAnimations()` / `svg.unpauseAnimations()` if any SMIL `<animate*>` elements exist.
6. **Reduced motion contract:** Inside `@media (prefers-reduced-motion: reduce)`, stop continuous signal animations (`animation: none !important; animation-play-state: paused !important;`) and keep static directional arrows, dashes, and numbered stage badges clearly visible so the diagram communicates 100% of the architecture statically.
7. **Typography & Khmer discipline:** Keep `<text>` at `>= 12px` in `viewBox` units (`>= 13px` titles, `>= 12px` sublabels), avoid crowding lines inside narrow boxes, and when Khmer text is present, apply `letter-spacing: 0` on Khmer text elements and increase node box height (`>= 96px`) and vertical `dy` spacing so stacked subscripts/vowels never touch borders.
8. **Responsive wrapper:** Wrap the `<svg>` in a responsive container (`max-width: 100%; overflow: visible` on SVG with `width: 100%; height: auto; display: block;`) so `390px` mobile and `1440px` desktop never produce horizontal scroll (`scrollWidth <= clientWidth`).
