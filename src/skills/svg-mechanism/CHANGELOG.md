# Changelog

## 0.1.0 - 2026-11-24

- Created `svg-mechanism` portable 10-layer skill for animated 2D technical architecture, data-flow, pipeline, protocol handshake, and mechanism explainer SVGs.
- Added semantic CSS token syncing (`design/tokens.css` first, fallback light/dark tokens), `<defs>` gradients/markers, semantic `<g>` layer hierarchy, Play/Pause `aria-pressed` controls, keyboard stage inspector, `prefers-reduced-motion: reduce` static fallback, and Khmer-safe typography rules.
- Added zero-dependency `engine/lint-svg.mjs` deterministic checker (`M1`–`M8`) verifying `viewBox`, `<defs>`, `<title>`/`<desc>`, Play/Pause, reduced motion, zero raw hex attributes, safe `<text>` margins, and light/dark tokens.
- Added 9 eval cases covering standalone HTML, React/JSX, design-foundation token reading, Khmer labels, vague prompt gate, and scope boundaries against `figure-craft`, `ui-craft`, and `motion-craft`.
