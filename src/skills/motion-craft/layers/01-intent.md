# Layer 01: Intent

1. Start from the goal the user states. Name the subject in their words.
2. Name the visitor and the one thing they should remember or do at the last scene. When unstated, use "understand the subject" and no invented action.
3. Read the pace from their words: calm, confident or energetic. Default to calm.
4. Translate plain words ("like a video", "walk through rooms", "slides sideways") with the vocabulary in `references/directions.md`. Never ask the user to pick a term. When the user already has a clip (`.mp4`/`.webm`) or asks for a webpage/coding-agent prompt (e.g. for Cursor) where the film plays as you scroll, this IS a web page plan (M2), not a video-generator prompt.
5. Hand layer 02: subject, visitor, ending, pace, and any named site or style.
