# Layer 10: Evidence

1. The test command's output is the evidence for every confirmed finding; the quoted line can be found in it.
2. The cited `file:line` and the worked input are the evidence for every suspect; a Red test is how it becomes confirmed.
3. Never write that the code is bug-free; write how many findings are confirmed and how many are suspect.
4. Say which test command ran and its counts, or that it did not run, and which files were read.

This is the last layer.
