# Layer 02: Context

1. The pages the user gives come first: read every given URL and every given saved page before any other page.
2. Read the task prompt for a required output format or an assigned file before you write anything (layer 06, steps 12 and 13).
3. A project file may be read with a read-only tool only to understand the question (what the feature is); it is never a web source, and code is never a business rule.
4. Never use memory as a source. What you remember about a site, a standard or a product is at most a hint for which page to fetch; once fetched, only the page's text counts.
5. Use only read-only tools (fetch, read, search, list), except to write the one file a task assigns (layer 06, step 13). Never edit or delete any other file and never run a command (R-web-research-11).
6. Reading a page is all you do with a site: never log in, fill a form, accept a cookie banner, buy or send data (R-web-research-10).

Hands to layer 03: the question, the given pages and the task's format or file.
