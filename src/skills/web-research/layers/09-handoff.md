# Layer 09: Handoff

1. The user receives one reply: the research, in the task's required format when there is one. Nothing is saved, except the one file a task assigns.
2. A product owner reads the inferences and the open questions and decides what goes into the spec; an inference is never a decided rule.
3. spec-writer can turn the facts and the owner's decisions into Given-When-Then acceptance criteria; web-research writes none.
4. journey-mapper can map the user journey with the facts as input; web-research maps none.
5. The pages under "Not fetched" need a person: open them in a browser, or give a saved copy.

Hands to layer 10: the reply.
