# Layer 10: Evidence

1. Keep the checker's output word for word (the result line is the proof; "passed" in your own words is not).
2. Keep the list of files written, with the path of each.
3. Keep the "Variables to add" list and the nearest variable used instead, so design-system can add them.
4. Keep what was assumed (stack not found, plain HTML and CSS used; a variant the user did not name) as lines in the reply's "Next", not hidden in a file.
5. Keep what was not done and why: components left in `components_pending`, the step that comes next, and any checker problem still open.
6. When a demo page was written, keep the path and the states it shows. Do not claim it was viewed unless a browser check was run.
