# Layer 03: Inputs

Required:

1. A screen or flow to review: the code of the screen, a step-by-step description of the flow, or both. A product name, a screen name or a link alone is not enough.

Optional:

2. The main goal of the user on this screen or flow, in the user's words.
3. A design-token file (layer 02, clause 6), the device (phone or desktop), and who the users are.

When one is missing:

4. No code and no description of what the screen or flow contains (for example only "Can you do a UX review of our checkout?"): reply exactly "Paste the screen's code or describe the flow step by step." Stop. Write nothing else: no heading, no findings, no general advice.
5. The main goal is not stated: take it from the input only when the input makes it plain (a form with one submit action, a flow with a named last step). Otherwise write "not stated" in the "Main goal:" line and add an open question asking for it.
6. A size, a gap, a timing or a result of an action is not shown: do not estimate it. Add an open question that names the control and the missing fact.
7. Never fill a gap with a guess about the product, its users or its other screens.
8. Hand the input, the main goal and the list of missing facts to layer 04.
