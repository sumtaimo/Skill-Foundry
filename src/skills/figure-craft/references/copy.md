# Copy

- MUST state the idea in one sentence before drawing.
- MUST keep labels to a few words and captions to one or two sentences.
- MUST write one idea per sentence in plain words.
- NEVER state facts the page does not keep true itself (no "tests passing" badges, live counts or version claims).
- NEVER use jargon in a label when a plain word exists.

Example:

- Idea: "The edge cache answers a request without asking the origin when it holds a copy."
- Labels: `Client`, `Request`, `Edge cache`, `Origin (skipped)`.
- Caption: "The request moves to the edge cache. The green light means a cache hit."
