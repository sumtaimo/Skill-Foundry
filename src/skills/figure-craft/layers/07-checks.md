# Layer 07: Checks

1. Run `lint(model)`. The result must have zero errors.
2. For each warning, change the shapes until it is gone, or write one sentence in the report saying why it stays.
3. Count the details: every labelled part has one to three, and each is listed in the parts table with the real feature it shows.
4. Answer every item in the [checklist](../references/checklist.md) yes or no. Any no blocks release.
5. If a browser is available, open the page and check: light, dark, 390px wide, reduced motion, and a console with no errors. Save a screenshot of each.
6. If no browser is available, say so in the report. Do not write that the browser checks passed.
7. Give the figure to a second reader and ask for the idea in one sentence. If it differs from the idea sentence, go back to layer 04.
