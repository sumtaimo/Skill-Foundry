# Layer 09: Handoff

1. Give the user the path of each file from layer 08.
2. Say how to regenerate: `node build-figure.mjs` in the output folder.
3. Say how to place the figure in their page: copy the inline SVG and the `tokensCss()` style block; do not copy colours.
4. List open items: assumptions about the real object, warnings left in place with their reason, checks that could not be run.
5. If another skill continues the work (copy review, accessibility audit, page build), pass it the idea sentence, the parts table and the file paths.
