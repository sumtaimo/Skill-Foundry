# Layer 01: Intent

Start from the goal the user states. This skill serves anyone: do not assume their domain.

1. Read the request and restate the goal in one sentence: "The figure shows that <subject> <does what>."
2. If the user gave no goal, or only a topic ("a refrigerator"), ask one question: "What should a reader understand after seeing it?" Then stop until they answer.
3. Name the reader (for example: customer, new engineer, student) and what they already know.
4. Pick the size: Figure (inline, one object), Hero (top of a page) or Page (several figures, one per idea).
5. If the goal needs more than one sentence, split it into several figures and confirm the split with the user.
6. If the request is a data chart, photo, logo, UI mockup or decoration, say this skill does not cover it and stop.

Hand to layer 02: the idea sentence, the reader, the size.
