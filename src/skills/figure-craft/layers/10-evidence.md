# Layer 10: Evidence

Record in `report.md`:

1. The input: the user's request, word for word, and the idea sentence it became.
2. The facts drawn and the source of each; the assumptions, marked as assumptions.
3. The files produced.
4. The lint result: number of errors and warnings, and the text of each warning left in place.
5. The checklist answers that were "no", or "all yes".
6. The browser checks run, and the ones not run with the reason.
7. Never write "passed" for a check that was not run.
