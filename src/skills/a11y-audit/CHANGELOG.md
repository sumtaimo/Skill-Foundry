# Changelog

## 1.0.0 - 2026-11-15

- First version: audits pasted HTML or JSX for what users cannot see and returns numbered findings, each with the element, a rule id, the WCAG 2.2 success criterion and level, who is affected and the fix as a diff.
- A zero-dependency script (`engine/audit.mjs`) runs 38 structural checks by search, so the list does not depend on the agent's eyes: language, title, viewport zoom, landmarks, headings, alt text, control and field names, labels, required state, errors, autocomplete, groups, keyboard access, focus order and traps, ARIA use, live regions, link purpose, label in name, tables, media, frames, nested controls and duplicate ids.
- Boundary with fixed sentences: no code; contrast, focus-ring style, spacing and target size (the polish skill owns them); usability of the flow; rewriting visible text; conformance certificates. Every finding names an element present in the input.
- S1: the skill tells the agent to run the script as ONE plain command with the path of the script (no `cd`, no shell variable, no pipe, no `;` or `&&`; a quoted here-document is the only extra shape, for an agent with no file-writing tool), and to say plainly on the first line of the reply, before the heading, when it could not run it (R-a11y-audit-17, layer 04 step 1, layer 06 step 11). The script's own output now says how to reply (it prints the two header lines to copy, says the run is its own result and not to add that anything was made by hand) and an error says what to do and gives the first-line sentence. New live cases `engine-one-command` and `engine-unavailable`.
- S6a: new check `lang-parts` (SC 3.1.2 Language of Parts, level AA, 39 checks now): text in another writing system than the page language (Khmer, Thai, Arabic, Hebrew, Han, kana, Hangul, Cyrillic, Devanagari, Greek, Latin) with no `lang` on it or above it is a finding, fixed with `lang` on the element or a `span` around the foreign words (R-a11y-audit-19). Without a page language the writing system most of the text uses is taken, and the note says so. Same-script languages (French on an English page) cannot be seen by the script and are a new manual test. New live case `lang-parts-khmer`.
- S6b: every reply header now holds one fixed sentence that contrast, focus-ring style, spacing and target size were skipped by rule, so "0 findings" is never read as "clean" (R-a11y-audit-18, layer 08). The script prints it with the counts.
- Ten core layers written as defined terms and numbered clauses; rules R-a11y-audit-1 to R-a11y-audit-16 in RULES.json.
