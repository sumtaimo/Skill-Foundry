1. Apply every rule in RULES.json (R-a11y-audit-1 to R-a11y-audit-16).

6. R-a11y-audit-10: with no code the reply is the sentence of layer 03, step 3, and nothing else.
7. R-a11y-audit-11 and 12: the reply has the four sections of layer 08, and the script was run.
8. R-a11y-audit-13 to 16 apply to the skill folder itself; the skill's lint checks them, and a run of the skill does not change them.
