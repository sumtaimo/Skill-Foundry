# Layer 02: Context

1. The goal text is the first source. Read it twice and mark every actor, action, rule, limit, message, role and end state it states.
2. When the user names a project file (a spec, a ticket, a page), read it with a read-only tool and use it as a source; cite it as `<path>:<line>`.
3. Never read other files to fill a gap, and never treat code you find as a business rule the user agreed to.
4. Never use what such features "usually" do (usual steps, usual limits, usual providers) as a source; a gap stays a gap (layer 04, step 9).
5. Use only read-only tools (read, search, list). Never write, edit or delete a file and never run a command (R-journey-mapper-6).
