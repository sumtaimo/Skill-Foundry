# Layer 03: Inputs

Required:

1. A goal: at least one action or one feature the user wants (a bare feature name such as "the checkout" is enough to start).
2. Optional: actors, rules, limits, messages, a named project file. What is missing becomes questions, never a reason to stop.

When the goal is missing:

3. The request names no feature and no action ("map the user journey for me", "do the workflow"): the whole reply is exactly "Tell me the feature goal in one or two sentences: who does what, and when it is done." Stop. Write no heading and no map.
4. A request for a regression checklist of a change or a diff has no goal either: follow layer 06, step 4.

Hands to layer 04: the goal and any named file.
