# Layer 10: Evidence

1. The quotes are the evidence: each one can be found in the goal or at the cited file and line.
2. The question list is the record of what the source does not say; it is never shortened by guessing.
3. Never write that the journey is "complete"; write how many steps were mapped and how many questions are blocking.
4. Say which sources were used: "the goal" and each file with its path.

This is the last layer.
