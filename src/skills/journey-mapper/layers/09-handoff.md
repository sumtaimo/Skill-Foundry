# Layer 09: Handoff

1. The user receives one reply: the map. Nothing is saved; the user or a harness copies it where it belongs.
2. A product owner answers the blocking questions first; a map with open blocking questions is not ready for build.
3. spec-writer can turn the map and the answers into Given-When-Then acceptance criteria; journey-mapper writes none.
4. test-planner can later list what to retest when a change to this journey is made; journey-mapper writes no checklist.
5. A designer or developer reads the seven slots per step as the list of states the screens must handle.

Hands to layer 10: the reply.
