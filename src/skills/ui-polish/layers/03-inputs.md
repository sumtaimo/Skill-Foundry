# Layer 03: Inputs

Required:

1. The input code of the finished screen: markup and the styles it uses (inline, in a style block, or as utility classes).

Optional:

2. The name of the screen, used in the reply heading. Without it, name the screen after its main heading text.
3. Which action is the primary action, in the user's words.

When one is missing:

4. No code at all, or only a description or a screenshot description of the screen: reply exactly "Paste the HTML and CSS of the finished screen you want polished." Stop. Produce no fixes, no headings and no code.
5. Markup with no styles at all: polish it by adding one style block that applies the scales, and say in "Open questions" that the original styles were not given.
6. Never fill a gap with a guess about colours, fonts or components the code does not show.
7. Hand the input code and the optional inputs to layer 04.
