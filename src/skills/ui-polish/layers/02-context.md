# Layer 02: Context

1. Treat the input code as the only source of elements, text, colours and structure.
2. Keep the code's own language: plain CSS stays plain CSS, JSX stays JSX, utility classes stay utility classes. Never convert one into another.
3. Keep the names the code uses for classes, ids, components and props exactly as written.
4. Treat every colour used on a button, link, badge or accent as a brand colour (layer 01) unless the user says it is not.
5. Do not look up the product, its design system or any other file. The skill runs in any project, and only the input code is known.
6. Note anything the user states about the screen (for example "this is our main checkout button") as the user's statement; it decides the primary action when the code does not.
7. Hand the input code and the user's statements to layer 03.
