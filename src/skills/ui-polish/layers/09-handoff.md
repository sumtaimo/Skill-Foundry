# Layer 09: Handoff

1. Give the reply of layer 08 as the whole answer.
2. Keep open questions in their own section, so they are not read as fixes.
3. Write no file unless the user asks for one; when they do, write the polished code to the path they name and nothing else. Never write to the token file.
4. For text changes, tell the user to use a copy-writing skill (for example copy-tight) on the polished code; this skill does not rewrite text.
5. For a token that is wrong or missing (a failing pair, a value with no matching token), the fix belongs in the token file: the user changes it by hand or with a design-token skill, then runs this polish again. Say so only in "Open questions".
6. Hand the counts of fixes per area, the contrast pairs and the ratio source to layer 10.
