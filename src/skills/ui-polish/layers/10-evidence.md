# Layer 10: Evidence

1. Keep the input code, word for word, next to the polished code.
2. Record the counts: fixes per area and colour pairs checked.
3. Record the result of the text search in layer 07, step 1: strings checked and strings missing (must be 0).
4. Record where the ratios came from: the contrast script (keep the lines it printed), the table, or the formula by hand.
5. Token mode: record the token file used, the count of token names in the polished code, the names not found in the file (must be 0), and each value with no matching token.
6. Record the reviewer answers of layer 07, steps 10 to 15, and list every "no".
7. List assumptions apart from facts, for example which action was taken as primary and why.
