# Page: skill detail page of "Skill Foundry" (files: page.html = markup, site.css = styles, ui-strings.txt = visible strings)

Product: a static website that lists AI agent skills. This is the detail page of ONE skill. The visitor arrives from the landing page card (or a search result) and is a first-time visitor.

Page order as built: skip link; header (logo, nav Collection / Install / For agents / Proof, theme button, language button); a "All skills" back link; a cover image labelled "Real output from an agent"; h1 = skill name; version, tags, roles, "Tested by a real agent: N of N cases pass"; "Copy install command" button; an in-page nav "Questions" with four links (What it does / What you type / What you get / How you know); section "What it does" (list of the ten layers); section "What you type" (one line to paste, copy button); section "What you get" (list of outputs, the full real agent answer with its request and a copy button, files in the package); section "How you know" (rules counts, changelog); section "Download" (zip, size, SHA-256); section "Install"; section "Banner to share"; footer.

Flow A: "Decide if this skill is the one I need" (read what it does, what I type, what I get).
Flow B: "Check it is real" (look at the real answer, tests, rules counts).
Flow C: "Install it" (command, zip, checksum).
Flow D: "Go back and compare with another skill".
