# Roadmap: candidate skills

Candidates only; none is built yet unless listed in `src/factory/registry.json`.

| Skill | Purpose |
|-------|---------|
| figure-craft | Build explanatory isometric figures and the pages that hold them |
| spec-writer | Write testable Given-When-Then acceptance criteria |
| ui-polish | Run a final pixel pass on a finished UI |
| copy-tight | Rewrite copy to be short and plain |
| a11y-audit | Check a page against accessibility basics and list fixes |
| changelog-writer | Turn a list of changes into a CHANGELOG entry |
| test-planner | Derive a regression checklist from a change description |
| svg-cover | Create a cover.svg that meets the factory preview limits |
