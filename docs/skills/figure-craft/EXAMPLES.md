# figure-craft examples

Each prompt becomes one concrete object. Labels name only parts the prompt gives; no numbers or facts are invented.

| Domain | Prompt | Object | Why |
|---|---|---|---|
| Software | "Show how a request passes through cache, server and database." | Three stacked boxes with a token sliding along one axis between them | Layers rest on each other; the slide shows the path without extra claims. |
| Physics | "Show a block being pushed across a floor." | A flat floor box with a block box resting on its top face | The floor is drawn first (L1); the block slides only along the x axis of the floor face (z = 0, L8) and loops. No forces or speeds are labelled because none were given. |
| Finance | "Show money moving from income into savings and spending." | One source box feeding two tray boxes on a shared base | Two destinations make the split visible; no amounts are shown because none were given. |
| Biology | "Show a cell with its nucleus." | A rounded box (cell) with a smaller box (nucleus) resting on its top face | Containment reads as resting; the nucleus sits centred on the face (L2). |
| Device | "Show a phone with its screen and button." | A thin tall box with a screen face detail and one dot as the button | Face details stay inside the front face, away from rounded corners; the dot is meaningful, not decoration. |
| Process | "Show an order going from placed to packed to shipped." | Three boxes in a row on a base, a parcel box sliding along the x axis | One looping story along one iso axis (L8); still under reduced motion (L7). |
