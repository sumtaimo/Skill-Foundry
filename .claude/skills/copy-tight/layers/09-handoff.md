# Layer 09: Handoff

1. Give the user the rewritten strings ready to paste, in the original order (one table row per string when there are two or more; every input line is there).
2. If you guessed a string's UI job (layer 03 step 2), say the guess in one line after the change list so the user can correct it.
3. List open items: a length limit not met, a sentence kept because cutting it changed meaning, legal text that a legal reviewer should own.
4. If the user next needs translation, long-form docs or a changelog entry, name that another skill or person handles it (changelog-writer for changelog entries).
