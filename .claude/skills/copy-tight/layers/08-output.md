# Layer 08: Output

The answer is plain text, no files. Produce exactly:

1. The line `Rewritten copy:` then the new strings, one per line, in the original order.
2. A blank line, then the line `What changed:` then at most 5 short bullets naming the kind of change (for example "cut filler", "active voice", "kept the amount").
3. For legal text: the original text unchanged under `Rewritten copy:`, then `What changed:` followed by `Legal text is returned unchanged.`
4. Fixed bullets: `- No change needed` for copy that is already tight; `- Length limit was not met; meaning kept.` when a user limit could not be met.
5. Quality bar: each string is shorter or equal in length, uses everyday words, keeps every number and name exactly, and fits its UI job (verb-first buttons, errors with a next step).
6. Keep the whole answer short: no preamble, no explanation of the skill, no alternatives unless the user asked for options.
